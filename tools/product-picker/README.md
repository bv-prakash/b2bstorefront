# Product picker and product slider

Two Document Authoring library pages share one catalog list. Each page inserts a different block.

| Picker | Page | Inserts |
| --- | --- | --- |
| Product Details | `picker.html` | One `product-details` block for the selected SKU |
| Product slider | `slider.html` | One `product-slider` block for the selected SKUs |

`config.json` `plugins.picker.rootCategory` is the category root (this store uses `2`). The slider layout and card counts are in `blocks/product-slider/defaults.js`.

## Document Authoring and Universal Editor

Both editors use the same picker pages and store the same block table.

| Block | Document Authoring | Universal Editor |
| --- | --- | --- |
| Product Details | **Products** library row opens `picker.html` and inserts the block. | **Product** field on the Product Details block opens `picker.html?editor=ue` and saves `selectSku`. |
| Product slider | **Product slider** library row opens `slider.html` and inserts the block. | **Products** field on the Product Slider block opens `slider.html?editor=ue` and saves `skus`, layout, mobile, tablet, and desktop. |

The Universal Editor setup is described in [Add Universal Editor support](#add-universal-editor-support). Each picker section below lists only the files that picker needs.

Shared files, required by whichever picker you keep:

| File | Role |
| --- | --- |
| `tools/product-picker/catalog.js` | Category tree, SKU search, and product list. It does not insert a block. |
| `tools/product-picker/picker.css` | Layout of that list. |
| `config.json` | `commerce-endpoint`, store headers, and `plugins.picker.rootCategory`. |

After a block model JSON changes, run `npm run build:json`. That refreshes `component-models.json`, `component-definition.json`, and `component-filters.json`.

The inserted table stores the selected SKUs in one `skus` cell, separated by commas. Universal Editor writes that same cell from the **Products** field.

| product-slider | |
| --- | --- |
| layout | slider |
| mobile | 1 |
| tablet | 2 |
| desktop | 4 |
| skus | ADB102,COCORESTCONFIG |

**Slider** shows that many cards at each breakpoint. Previous and Next appear only when more products exist than fit. **Grid** uses the same counts as columns and does not show arrows. Each card shows the image, name, price, add to cart, wishlist, and compare. The price matches the product list.

## Add Universal Editor support

Universal Editor shows a picker inside the block properties. The **Product** field on Product Details and the **Products** field on Product Slider open the same category tree and SKU search as Document Authoring. The Products field also shows Slider or Grid and the mobile, tablet, and desktop counts.

Add at least one of the two pickers above first. Universal Editor support reuses their pages.

How it loads:

1. `component-models.json` gives `selectSku` the component `product-picker` and `skus` the component `product-slider-picker`.
2. `head.html` adds `tools/product-picker/ue.html` to the Universal Editor extension list. `ue.da.live` puts its own `urn:adobe:aue:config:extensions` meta tag before `head.html`, and the editor reads only that first tag, so the script adds the picker URL to that first tag.
3. `ue.js` registers both components and points them at `picker.html?editor=ue` and `slider.html?editor=ue`.
4. With `?editor=ue`, the picker page connects to the field with `@adobe/uix-guest`. Selecting a product saves `selectSku`. **Add products** saves `skus` as a comma-separated list, along with layout, mobile, tablet, and desktop.
5. The page adds the `picker-ue` class. That class gives the category tree and product list fixed heights, and the page reports its own height to the field. Sizing by `100vh` in the field iframe makes the field grow without end, because the editor resizes the iframe to the reported height.

Universal Editor hides a field whose component has no renderer. When **Product** or **Products** is missing, the extension did not load. To load it by hand, add `?ext=` to the editor URL:

`https://experience.adobe.com/#/@2E259F2A6ABE32430A495C0F/aem/editor/canvas/main--b2bstorefront--bv-prakash.ue.da.live/index?ext=https://main--b2bstorefront--bv-prakash.aem.page/tools/product-picker/ue.html`

Universal Editor reads `component-models.json`, `head.html`, and the picker pages from the published code branch. Push the changes before testing in the editor.

Files to add:

| File | Why |
| --- | --- |
| `tools/product-picker/ue.html` | Extension page that Universal Editor loads. |
| `tools/product-picker/ue.js` | Registers the `product-picker` and `product-slider-picker` renderers. Keep only the renderer for the picker in use. |

Files to modify:

| File | Change |
| --- | --- |
| `head.html` | Add the `addProductPickerExtension` script that adds `tools/product-picker/ue.html` to the `urn:adobe:aue:config:extensions` meta tag on `*.ue.da.live`. |
| `tools/product-picker/catalog.js` | Add `UE_EXTENSION_ID`, `isUniversalEditorPicker()`, `connectUniversalEditor()`, and `syncFieldHeight()`. Add the `picker-ue` class when the page opens with `?editor=ue`. `connectAuthoring()` skips the Document Authoring SDK in that case. |
| `tools/product-picker/picker.css` | Add the `.picker-ue` rules: one column, fixed category tree and product list heights, and no `100vh`. |
| `tools/product-picker/picker.js` | When connected to Universal Editor, save the SKU with `host.field.onChange(sku)`. Otherwise insert the Document Authoring table. |
| `tools/product-picker/slider.js` | When connected to Universal Editor, preselect the current `skus`, save `skus` with `host.field.onChange`, and update layout, mobile, tablet, and desktop with `editorActions.update`. Otherwise insert the Document Authoring table. |
| `blocks/product-details/_product-details.json` | `selectSku` uses component `product-picker`. |
| `blocks/product-slider/_product-slider.json` | `skus` uses component `product-slider-picker`. |
| `blocks/product-slider/product-slider.js` | Read `skus` as a comma-separated list or a JSON array. Rows with a SKU in the first cell still render. |
| `component-models.json` | Regenerated by `npm run build:json`. |

| File | When |

| File | Change |
| --- | --- |
| `head.html` | Remove the `addProductPickerExtension` script. |

| `component-models.json` | Regenerated by `npm run build:json`. |

Keep `blocks/product-slider/product-slider.js` reading `skus`. Document Authoring inserts that same row.
